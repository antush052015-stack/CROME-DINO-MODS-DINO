# CROME-DINO-MODS-DINO

🌐 [English Version of README available here](README_en.md)


это интересный сборник модов для Chrome Dino

на данный момент это репозиторий имеет в себе 8 модов это:
DINO MEGAHACK V6.1 , V18.3 +  , 
DINO BOT , 
DINO MAKER OS , 
DINO MAKER OS SPECIAL , 
COLOR DINO , 
DINO EDITOR(OLD) , 
MULTI PLAYER MOD , 
DINO PLAT MOD(OLD) , 





1. 🦖 MEGA HACK (Мега-Хак)
Тип: Чит-пак (расширение возможностей)

Что делает:
Добавляет в Chrome Dino огромное меню (открывается по Tab), в котором собрано 50+ читов и функций:

Основные возможности:
GODMODE — бессмертие.
AUTO BOT — автопилот.
INF FLY — полёт.
DESTROYER — уничтожение препятствий.
SPEED HACK — изменение скорости.
JUMP HEIGHT — высота прыжка.
GRAVITY — контроль гравитации.
MOONWALK, MATRIX, GHOST, UPSIDE DOWN, RGB PARTY — визуальные эффекты.

Дополнительно:
Погода (дождь, снег, метеоры, ураган).
3D-режимы (поворот экрана, воксельный рендер).
Трансформации (в кактус, в птицу).
Смена суток (день/вечер/ночь).
Dev Patcher (ввод своего JS-кода).
Для чего: для фана и экспериментов, можно почувствовать себя «хозяином» игры.

2. 🎨 DINO MAKER OS
Тип: Редактор уровней + игровые режимы

Что делает:
Это целая система, которая позволяет:
Создавать собственные уровни в редакторе.
Играть в платформер с собственной физикой.
Тестировать оригинальный режим.

Режимы:
Классика — обычная игра.
Редактор — ставишь блоки и кактусы.
Платформер — прыгаешь по блокам.
Оригинальный тест — бесконечный забег.
Инструменты редактора:
Блок, Кактус, Ластик, Очистить.
Для чего: для творчества — можно строить свои уровни и проходить их.

3. COLOR DINO
Тип: Графический мод

Что делает:
Перехватывает отрисовку спрайтов и перекрашивает их в реальном времени.

Цветовая схема:
Динозаврик → коричневый.
Кактусы → зелёные.
Земля → песочная.
Облака → голубые.
Game Over → красный.
Цифры счёта → оранжевые.
Для чего: чтобы игра выглядела цветной и необычной.

4. MULTIPLAYER MOD
Тип: Игровой режим на двоих

Что делает:
Добавляет второго динозаврика, которым управляет второй игрок.

Управление:
Игрок 1 — стрелочки + пробел.
Игрок 2 — WASD (или настраиваемые клавиши).

Особенности:
Оба умирают при столкновении.
Возрождение через 5 секунд.
Game Over только если оба мертвы.
Меню по F1.
Для чего: для игры вдвоём за одним компьютером.

5. 🎮 DINO MAKER OS SPECIAL
Тип: Расширенный редактор + платформер

Что делает:
Это «прокачанная» версия DINO MAKER OS с огромным количеством новых блоков и функций.

Новые блоки:
Монета, Портал, Движущийся блок, Склон, Золото, Лёд, Лава, Вода, Облако, Шип, Пружина, Гриб, Звезда, Сердце, Бомба, Часы, Ключ, Сундук, Трава, Снег, Грязь, Огонь и другие.

Функции:
Сохранение/загрузка уровней.
Скачивание .dmos файлов.
Загрузка из .dmos.
Настройки (анимации, доп. блоки, счётчик монет).
Рандомная генерация уровня.
Прокрутка камеры (W/S).
Замена текстур.
Дублирование блоков (Ctrl+D).
Режим отладки.
Счётчик монет с возможностью скрытия.
Для чего: для создания сложных уровней с разными механиками.

6. 🚀 DINO PLAT MOD (OLD)
Тип: Платформер с готовыми платформами

Что делает:
Включает режим, в котором уже есть заранее созданные платформы, по которым можно прыгать.

Особенности:
Своя физика (гравитация, прыжки).
Платформы уже расставлены.
Управление стрелочками и пробелом.

Для чего: быстрый старт — не нужно строить уровень, можно сразу играть.

7. 🏗️ DINO EDITOR (OLD)
Тип: Редактор уровней с мышкой

Что делает:
Позволяет кликать мышкой по экрану и ставить блоки в любом месте.

Особенности:
Клик мышкой = создать блок.
Своя физика прыжков.
Можно ходить по своим блокам.
Управление стрелочками и пробелом.
Для чего: для тех, кто хочет быстро построить уровень, не заходя в меню.

8. 🤖 DINO BOT
Тип: Автопилот (бот)

Что делает:
Играет сам за вас: автоматически прыгает через кактусы и приседает под птицами.
Как работает:

Смотрит на ближайшее препятствие.
Если оно близко — прыгает или приседает.
Работает автоматически.

Настройки:
JUMP_DISTANCE — на каком расстоянии прыгать.
DUCK_DISTANCE — когда приседать.
Для чего: чтобы посмотреть, как игра проходит сама, или чтобы не играть вручную.

#  📦 Как установить любой мод для Chrome Dino
📁 Что вам понадобится
Браузер Google Chrome (или любой на Chromium).

Файл dino.html из этого репозитория (скачайте или откройте его).

Код нужного мода (файлы .txt или .js в репозитории).

🚀 Шаг 1. Откройте игру
Скачайте репозиторий или просто откройте dino.html (дважды кликните).

Или откройте chrome://dino в Chrome (если используете стандартную версию).
Важно: старые моды (OLD) лучше работают на dino.html, так как там устаревшая версия игры.

🛠️ Шаг 2. Откройте консоль разработчика
Нажмите F12 (или Ctrl + Shift + J).

Перейдите на вкладку Console (Консоль).

Если увидите предупреждение о вставке кода, нажмите разрешить.

📋 Шаг 3. Скопируйте код мода
Откройте файл мода (например, megahack.txt или megahack.js).

Выделите весь код: Ctrl + A.

Скопируйте: Ctrl + C.

📥 Шаг 4. Вставьте и запустите
Кликните в поле консоли.

Вставьте код: Ctrl + V.

Нажмите Enter.

Готово! Мод активирован. Обычно в консоли появится сообщение об успешной загрузке.

🧩 Особенности для конкретных модов
Мод	Как запустить после вставки кода
🦖 MEGA HACK	Нажмите Tab — откроется меню читов
🎨 DINO MAKER OS	Появится меню выбора режима
🌈 COLOR DINO	Эффект применится сразу
🎮 MULTIPLAYER	Нажмите F1 — меню мультиплеера
🎮 DINO MAKER OS SPECIAL	Требует MEGA HACK (установите сначала). Затем нажмите Tab для настроек
🚀 DINO PLAT MOD (OLD)	Требует MEGA HACK. Управление стрелочками и пробелом
🏗️ DINO EDITOR (OLD)	Требует MEGA HACK. Кликайте мышкой по экрану
🤖 DINO BOT	Требует MEGA HACK. Бот начнёт играть сам
⚠️ Важные замечания
Порядок установки: если мод требует MEGA HACK, всегда сначала установите его, а затем нужный мод.

Не запускайте DINO MAKER OS и DINO MAKER OS SPECIAL одновременно — они конфликтуют.

Если мод не работает, перезагрузите страницу и попробуйте снова.

Все действия выполняются в одной вкладке, не закрывайте игру после вставки.

🎮 Советы
Держите файлы модов открытыми в текстовом редакторе (Блокнот, Notepad++), чтобы быстро копировать.

Для снятия скриншотов используйте Bandicam, Lightshot или встроенный инструмент Chrome.
