# CHROME-DINO-MODS-DINO
This is an interesting collection of mods for Chrome Dino

At the moment, this repository has 8 mods:
DINO MEGAHACK V6.1 , V18.3 + ,
DINO BOT,
DINO MAKES US,
DINO MAKES US SPECIAL,
COLOR DINO ,
DINO EDITOR(OLD) ,
MULTI PLAYER MOD ,
DINO PLAT MOD(OLD),





1. 🦖 MEGA HACK (Мега-Хак)
Type: Cheat-pak (expansions)

What does:
Adds to Chrome Dino a huge menu (открывается по Tab), which contains 50+ cheats and functions:

Main features:
GODMODE — бессмертие.
AUTO BOT — автопилот.
INF FLY — полёт.
DESTROYER
SPEED HACK — change speed.
JUMP HEIGHT — высота прижка.
GRAVITY — control of gravity.
MOONWALK, MATRIX, GHOST, UPSIDE DOWN, RGB PARTY — visual effects.

Additionally:
Weather (rain, snow, meteors, hurricane).
3D modes (screen rotation, voxel rendering).
Трансформации (в какту, в птицу).
Смена суток (день/вечер/ночь).
Dev Patcher (ввод своего JS-кода).
Для чего: для фана и экспериментов, можно пособистовать себя «хозяином» игры.

2. 🎨 DINO MAKES US
Type: Level editor + game modes

What does:
This is a whole system that allows:
Create your own levels in the editor.
Play platforms with own physics.
Test the original mode.

Modes:
Classic — обычная игра.
Editor — put blocks and cactuses.
Платформер — пригаешь по блокам.
Original test — infinite run.
Editor's tools:
Блок, Кактус, Ластик, Очистить.
Для чего: для творчества — можно строить свои уровни и отличной их.

3. COLOR DINO
Type: Graphic mod

What does:
Intercepts the drawing of sprites and repaints them in real time.

Color scheme:
Динозаврик → brown.
Кактусы → зелёные.
Земля → песочная.
Clouds → blue.
Game Over → красный.
Цифры счёта → orange.
For what: to make the game look colorful and unusual.

4. MULTIPLAYER MOD
Type: Игровой режим на двоих

What does:
Adds a second dinosaur controlled by the second player.

Management:
Player 1 — arrows + space.
Player 2 — WASD (or customizable keys).

Features:
Both die in collision.
Возрождение через 5 секунд.
Game Over only if both are dead.
Menu on F1.
For what: to play together on one computer.

5. 🎮 DINO MAKES US SPECIAL
Type: Extended editor + platformer

What does:
This is a "pumped" version of DINO MAKER OS with a huge number of new blocks and functions.

New blocks:
Монета, Портал, Движущийся блок, Склон, Золото, Лёд, Лава, Вода, Облако, Шип, Пружина, Гриб, Звезда, Сердце, Бомба, Часы, Ключ, Синдук, Трава, Снег, Грияз, Огонь и другие.

Functions:
Saving/loading levels.
Скачивание .dmos file.
Загрузка из .dmos.
Settings (animations, additional blocks, currency calculator).
Random level generation.
Прокрутка камеры (W/S).
Замена текстур.
Dubbing blocks (Ctrl+D).
Mode of debugging.
Счётчик монет с можностью скриты.
For what: to create complex levels with different mechanics.

6. 🚀 DINO PLAT MOD (OLD)
Type: Platforms with ready-made platforms

What does:
It includes a mode in which there are already pre-created platforms on which you can jump.

Features:
Своя физика (gravitation, прижки).
Платформы already расставлены.
Управление стрелочками и белом.

For what: quick start — you don't need to build a level, you can play immediately.

7. 🏗️ DINO EDITOR (OLD)
Type: Level editor with mouse

What does:
Allows you to click the mouse on the screen and place blocks anywhere.

Features:
Click mouse = create block.
Своя физика прижков.
You can walk on your blocks.
Управление стрелочками и белом.
For what: for those who want to quickly build the level without entering the menu.

8. 🤖 DINO BOT
Type: Autopilot (bot)

What does:
It plays itself for you: it automatically jumps through cacti and sits under birds.
How it works:

Look at the nearest obstacle.
Если оно близко — jumps or squats.
It works automatically.

Settings:
JUMP_DISTANCE — on what distance to jump.
DUCK_DISTANCE — когда приседать.
For what: to see how the game plays itself, or not to play manually.

# 📦 How to install any mod for Chrome Dino
📁 What you will need
Браузер Google Chrome (or any Chromium).

File dino.html from this repository (download or open it).

Code of the required mod (files .txt or .js in the repository).

🚀 Step 1. Open the game
Download the repository or simply open dino.html (double click).

Or open chrome://dino in Chrome (if you use the standard version).
Important: old mods (OLD) work better on dino.html, because there is an outdated version of the game.

🛠️ Step 2. Open the developer console
Press F12 (or Ctrl + Shift + J).

Go to the Console tab.

If you see a warning about inserting a code, click OK.

📋 Step 3. Copy the mod code
Open the mod file (for example, megahack.txt or megahack.js).

Select all code: Ctrl + A.

Copy: Ctrl + C.

📥 Step 4. Insert and start
Click on the console field.

Insert code: Ctrl + V.

Press Enter.

Готово! Mod activated. Usually a message about a successful download will appear in the console.

🧩 Features for specific mods
Mod How to start after inserting the code
🦖 MEGA HACK Click Tab — откроется меню читов
DINO MAKER OS
🌈 COLOR DINO The effect will be applied immediately
🎮 MULTIPLAYER Press F1 — menu multiplayer
🎮 DINO MAKER US SPECIAL Requires MEGA HACK (uninstall first). Then press Tab for settings
🚀 DINO PLAT MOD (OLD) REQUIRES MEGA HACK. Управление стрелочками и белом
🏗️ DINO EDITOR (OLD) REQUIRES MEGA HACK. Click the mouse on the screen
🤖 DINO BOT REQUIRES MEGA HACK. Бот начнёт играть сам
⚠️ Important notes
Installation order: if the mod requires MEGA HACK, always first install it, and then the desired mod.

Do not run DINO MAKER OS and DINO MAKER OS SPECIAL at the same time — they conflict.

If the mod does not work, reload the page and try again.

All actions run in one tab, don't close the game after insertion.

🎮 Councils
Keep mod files open in a text editor (Bloknot, Notepad++) to quickly copy.

To take screenshots, use Bandicam, Lightshot, or the built-in Chrome tool.
